[CampusFind](CampusFind/README.md) is a Python desktop application for reporting and managing lost and found items on campus. Its source, assets, local data, and supporting files are grouped inside the `CampusFind` folder.

Open PowerShell in this folder and follow the project's setup guide:

```powershell
Set-Location .\CampusFind
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r .\requirements.txt
.\.venv\Scripts\python.exe .\main.py
```

See the CampusFind guide for initial administrator setup and optional sample data. All application paths are relative to its own project folder.
