# Python Problem Solving

**25BTRAD051**

These programs use Python's standard library. Run them in PowerShell from this folder, using the paths below. The menu-driven programs prompt for input.

| Project | Description |
| --- | --- |
| [Unit 1 assignments](25BTRAD051_assignmenttask_unit1_codes/README.txt) | Combined menu for 18 tasks, with saved output images |
| [Attendance tracker](25BTRAD051_Problem%20Solving_Attendance%20Tracker/main.py) | Add students, record attendance, and display attendance percentages |
| [OTP generator](25BTRAD051_Problem%20Solving_OTP%20Generator/main.py) | Generate a sample six-digit code using Python's random module |
| [Unit converter](25BTRAD051_Problem%20Solving_Unit%20Converter/main.py) | Convert between centimetres and inches |
| [Bill generator](25BTRAD051_Problem%20Solving_Bill%20Generator/25BTRAD051_Bill_Generator.py) | Enter items, quantities, and prices to calculate a bill |
| [Sales data analyzer](25BTRAD051_Problem%20Solving_Sales%20Data%20Analyzer/25BTRAD051_Sales_Data_Analyzer.py) | Maintain product sales and calculate sales totals |
| [Student grading automation](25BTRAD051_Problem%20Solving_Student%20Grading%20Automation/25BTRAD051_Student_Grading_Automation.py) | Assign a grade from a student's marks |

```powershell
python '.\25BTRAD051_assignmenttask_unit1_codes\assignment_unit1_all_18_tasks.py'
python '.\25BTRAD051_Problem Solving_Attendance Tracker\main.py'
python '.\25BTRAD051_Problem Solving_OTP Generator\main.py'
python '.\25BTRAD051_Problem Solving_Unit Converter\main.py'
```

The former `USN_Problem Solving` programs are merged into the matching project folders and renamed with `25BTRAD051`. The attendance, OTP, and unit-converter folders each retain `main.py` and also contain the additional `25BTRAD051_Attendance_Tracker.py`, `25BTRAD051_OTP_Generator.py`, or `25BTRAD051_Unit_Converter.py` program. Run either version by its filename; they provide different interactions.

The Unit 1 folder includes the original menu-driven `assignment_unit1_all_18_tasks.py` and the additional sequential `25BTRAD051_Tasks_1_to_18.py`. The sequential version runs all tasks and asks for input as it proceeds.

The OTP generator is a programming exercise, not an authentication service. Output images are saved examples and can differ from a new run.
