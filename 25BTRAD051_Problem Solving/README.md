# Python Problem Solving

**25BTRAD051**

These programs use Python's standard library. Run them in PowerShell from this folder, using the paths below. The menu-driven programs prompt for input.

| Project | Description |
| --- | --- |
| [Unit 1 assignments](25BTRAD051_assignmenttask_unit1_codes/README.txt) | Combined menu for 18 tasks, with saved output images |
| [Attendance tracker](25BTRAD051_Problem%20Solving_Attendance%20Tracker/main.py) | Add students, record attendance, and display attendance percentages |
| [OTP generator](25BTRAD051_Problem%20Solving_OTP%20Generator/main.py) | Generate a sample six-digit code using Python's random module |
| [Unit converter](25BTRAD051_Problem%20Solving_Unit%20Converter/main.py) | Convert between centimetres and inches |

```powershell
python '.\25BTRAD051_assignmenttask_unit1_codes\assignment_unit1_all_18_tasks.py'
python '.\25BTRAD051_Problem Solving_Attendance Tracker\main.py'
python '.\25BTRAD051_Problem Solving_OTP Generator\main.py'
python '.\25BTRAD051_Problem Solving_Unit Converter\main.py'
```

The OTP generator is a programming exercise, not an authentication service. Output images are saved examples and can differ from a new run. The Unit 1 README preserves its source notes; its referenced source PDF is not included in this repository.
